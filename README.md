## 🚀 Features

* 🔍 Search movies by name
* 🎬 Display movie cards with poster, title, year, and type
* 📄 Click on a movie to view detailed information
* ⭐ Shows rating, plot, cast, runtime, and more
* 📱 Fully responsive design (mobile + desktop)
* ⚡ Smooth animations and hover effects
* 🔙 Back navigation with fallback support

---

## 🛠️ Tech Stack

* **React.js**
* **Tailwind CSS**
* **React Router DOM**
* **OMDb API**

## ⚙️ Installation & Setup

1. Clone the repository:

```bash id="s8n1jm"
git clone https://github.com/01-coder07/movie-information.git
```

2. Navigate to project folder:

```bash id="9h3o6k"
cd movie-information
```

3. Install dependencies:

```bash id="m9q8fi"
npm install
```

4. Start development server:

```bash id="3i4t5v"
npm run dev
```

## 🎯 Key Functionalities

* Dynamic routing using **React Router**
* Fetching movie data using **useEffect**
* Conditional rendering for search & default movies
* Handling missing data (`Poster: "N/A"`)
* Responsive UI using Tailwind CSS
